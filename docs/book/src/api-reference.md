# Programmer Reference

The API reference is generated by `cargo doc` from the doc comments in the
source, and published with this guide on every push to `main`. Private items
are included, because every crate here is internal to the `xil` binary.

| Crate | What |
| --- | --- |
| [`xil`](api/xil/index.html) | the `xil` binary: command table and one module per stage (`crates/xil-cli`) |
| [`xil_core`](api/xil_core/index.html) | workspace paths, config models, edit journal, logging |
| [`xil_audio`](api/xil_audio/index.html) | PCM math matching pydub/audioop, ffmpeg bridge, ID3/WAV tags |
| [`xil_api`](api/xil_api/index.html) | ElevenLabs / Anthropic / gTTS clients |
| [`xil_workers`](api/xil_workers/index.html) | JSON-over-stdio client for the Python ML workers |
| [`xil_web`](api/xil_web/index.html) | `xil gui`: the axum + htmx dashboard |

To build it locally:

```bash
cargo doc --workspace --no-deps --document-private-items --open
```
